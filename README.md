# Laboratory Work 4
This project is a laboratory/practical work for the "Computer Technologies and Programming" course. It contains programs for working with arrays of structures and parsing strings in C.

## Programs Included

### 1. Route Search (`task1.c`)
This program searches for a transport route by its number within a pre-defined array of structures and prints its details.

### 2. Word Length (`task2.c`)
This program reads a sentence from the user and calculates the length of the n-th word.

## How to Compile and Run
```bash
gcc filename.c -o out
./out
```

## Example Usage

### task1.c
```text
Введіть номер маршруту для пошуку: 15
Маршрут знайдено!
  Номер:    15
  Напрямок: ЦУМ — Кінотеатр "Луцьк"
```

### task2.c
```text
Введіть речення: This is a test sentence.
Введіть порядковий номер слова: 4
Довжина слова № 4: 4 символів.
```
